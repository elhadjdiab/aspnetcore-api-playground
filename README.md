# aspnetcore-api-playground

Week 0 — Setup & baseline (asp.net core learning path)

Goals
- Install tools and verify environment
- Create a small C# console app to refresh syntax/async/LINQ
- Initialize a GitHub repo and push this starter project

Environment checklist
- .NET SDK (latest LTS): https://dotnet.microsoft.com/
- Editor: Visual Studio or VS Code + C# extension
- Git: https://git-scm.com/
- Optional: Postman / HTTPie, Docker

How to run
1. dotnet run (from AspNetCore.Playground folder)
2. See console output for LINQ and async demo

Deliverables for Week 0
- [x] .NET SDK installed and verified
- [x] Editor installed and tested
- [x] GitHub repo created and repo URL recorded
- [x] Console app created, run locally and committed to repo

Next steps (Week 1)
- C# fundamentals deeper: LINQ, async/await, OOP
- Start the Web API template: dotnet new webapi
